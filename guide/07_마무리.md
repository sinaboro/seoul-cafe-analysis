# 7장. 마무리 - 나만의 분석, 발표, 점검표

## 7-1. 나만의 분석 아이디어

예제를 그대로 내면 모두 같은 결과가 나온다. 아래에서 **두 개 이상** 골라 내 프로젝트에 더하자.

| 아이디어 | 쓰는 데이터 | 난이도 |
|---|---|---|
| 요일·주말 패턴 (주말에 강한 동) | 추정매출의 요일 열 | ★ |
| 프랜차이즈 비율이 높은 동은 점포당 매출이 다를까? | 점포 | ★ |
| 개업률·폐업률 추이 - 커피 시장이 커지나 줄어드나 | 점포 8분기 | ★★ |
| 객단가(건당 매출)가 높은 동 - 고급 카페 상권 | 매출액 ÷ 매출건수 | ★★ |
| 커피 vs 제과점·패스트푸드 비교 | 1장 코드에서 업종만 바꿔 받기 | ★★ |
| 20대 비중이 높은 동 = 대학가? | 연령대별 매출 | ★★ |
| **지도**: 행정동 경계에 점수를 색으로 칠하고 커피숍 위치 찍기 | **9장**에 따라 하기 (Leaflet, GeoJSON) | ★★★ |
| 지도 넓히기: 브랜드별 색, 최근 개업 가게, 점 묶기 | 9장 '직접 해 보기' | ★★★ |

> 지도는 **9장**에 데이터 받기부터 화면까지 단계별로 정리해 두었다. 9장을 그대로 따라 한 뒤, 색칠 기준이나 점의 종류를 바꿔 나만의 지도로 만들자.

## 7-2. 발표 구성 (10분 예시)

1. **질문** (1분) - "서울에서 카페를 차린다면 어디?" 처럼 한 문장
2. **데이터** (1분) - 출처, 기간(2024년 3분기 ~ 2026년 2분기), 추정 매출이라는 한계
3. **발견 3가지** (4분) - 그래프 + 숫자 + 한 문장. 예상과 다른 결과(3장 Q5)가 있으면 꼭 넣는다
4. **추천** (2분) - 창업 점수 상위 동과 가중치를 그렇게 정한 이유
5. **시연** (2분) - 배포 주소에서 자치구·슬라이더를 바꿔 보여 주기 (직전에 한 번 열어 서버를 깨워 둔다)

> 시연이 실패할 때를 대비해 **화면 녹화 영상**이나 캡처를 준비해 두자.

## 7-3. 제출 전 점검표

| 구분 | 점검 |
|---|---|
| 데이터 | 출처와 기간을 적었다 · 추정 매출이라는 점을 밝혔다 |
| 데이터 | 줄 수·분기·행정동 수를 확인했다 (1장 1-4) |
| 분석 | 질문마다 그래프 1개 + 숫자가 들어간 해석 1문장 |
| 분석 | 관계와 원인을 구분해서 썼다 (3장 3-4) |
| 분석 | 나만의 분석을 2개 이상 더했다 (7-1) |
| 서비스 | `uvicorn` 으로 켜고 브라우저에서 모든 차트가 뜬다 |
| 서비스 | 없는 자치구·잘못된 가중치에도 화면이 멈추지 않는다 |
| 배포 | 공개 주소가 휴대폰에서도 열린다 (8장) |
| 코드 | 파일 맨 위에 흐름 설명, 중요한 줄에 주석 |
| 보안 | `.env`(인증키)가 GitHub 에 올라가지 않았다 |

## 7-4. 평가 기준 예시

| 항목 | 비중 | 잘한 프로젝트 |
|---|---|---|
| 질문과 결론 | 25% | 질문이 분명하고, 결론이 숫자로 뒷받침된다 |
| 데이터 처리 | 20% | 결측·0 나누기·병합 누락을 확인하고 처리했다 |
| 분석의 깊이 | 20% | 예제 밖의 분석을 더했고, 예상과 다른 결과도 설명했다 |
| 서비스 완성도 | 20% | API 와 화면이 오류 없이 동작하고, 조건을 바꿔 볼 수 있다 |
| 발표·코드 품질 | 15% | 10분 안에 핵심 전달, 코드에 주석과 흐름 설명 |

## 7-5. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `인증키가 없습니다` | `.env` 위치·이름이 다르다 | 프로젝트 폴더 바로 아래 `.env`, 줄은 `SEOUL_API_KEY=키` |
| API 응답에 `INFO-200` (데이터 없음) | 아직 공개되지 않은 분기 | 사이트에서 최신 분기를 확인하고 `QUARTERS` 를 고친다 |
| 합쳤더니 빈 값이 잔뜩 | 코드 열을 숫자로 읽었다 | `dtype={"ADSTRD_CD": str}` |
| seaborn 그래프의 한글이 □□□ | 한글 글꼴 설정이 없다 | `sns.set_theme(font="Malgun Gothic")` (Mac 은 AppleGothic) |
| `uvicorn` 실행 시 `No module named service` | 실행 위치가 다르다 | 프로젝트 폴더(`seoul-cafe-analysis`)에서 실행 |
| 화면은 뜨는데 차트가 비어 있다 | API 오류 | F12 → 콘솔·네트워크 탭에서 빨간 요청 확인 |
| 차트가 겹치거나 깜빡인다 | 이전 차트를 지우지 않았다 | `charts[name].destroy()` |
